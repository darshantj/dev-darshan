# What we are building

This site documents how to build a full-stack, AI-powered application end to end:
the decisions, the tools and the code, explained for someone who knows computer
science but hasn't built a production system yet.

The worked example is **Darkroom**, an AI image generator. You write a prompt,
a model running on a local GPU turns it into an image, and other people can
browse, bookmark and remix what you made. The ideas carry over to any app that
puts an AI model behind a web API.

::: info Work in progress
The docs follow the build. Pages appear as each part is finished.
:::
